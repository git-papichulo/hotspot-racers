# Hotspot Racers

Offline LAN / hotspot top-down racing game for up to 6 players (like Mini Militia, but with cars).

- One phone hosts (turn on its Wi-Fi hotspot, or use a shared router). No internet needed.
- Everyone else joins the same Wi-Fi, opens the app and taps **Join a race**.
- Host picks the track, laps, bot count, bot skill; everyone picks their own car colour.
- Built with plain Flutter (zero packages) for low-end / Android Go phones. APK is built by GitHub Actions.

Controls: hold the left half of the screen to steer left, the right half to steer right. Hold both to brake. Gas is automatic.
